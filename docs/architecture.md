# Устройство

## Процессы

Три контейнера и одноразовый fetch (`compose.yaml`), у web и worker по своему
образу из одного `Dockerfile`:

```
 браузер
    |  HTTPS :AUDIOBUX_PORT
    v
 +--------------------+   run/worker.sock    +--------------------------+
 | web                | -------------------> | worker                   |
 | FastAPI + интерфейс|  JSON, 7 методов     | очередь, конвейер, GPU   |
 | только чтение      |                      | модели, llama-server     |
 +--------------------+                      +--------------------------+
    |  incoming/ (пишет)                          |  HTTP, сеть cover_in
    |  library/  (читает)                         v
    |  web/      (пишет)                     +--------------------------+
                                             | cover                    |
                                             | ищет обложку в сети      |
                                             +--------------------------+
```

**fetch** (`audiobux fetch`, образ worker). Ставит рантайм моделей (torch с CUDA,
F5, faster-whisper, RUAccent, llama-server) в `runtime/`, качает модели в
`models/` и завершается. Единственный с образом worker, у кого есть выход в
интернет (сеть `default`); книг не открывает, карты не берёт. Идёт в фоне,
`install.sh` его не ждёт.

**worker** (`audiobux worker`). Стартует сразу, первую книгу берёт, когда fetch
всё положил на место. Держит очередь в SQLite, озвучивает книги по
одной, работает с картой. Выхода в сеть нет: он только во внутренней сети
`cover_in` (`internal: true`), с `HF_HUB_OFFLINE=1`. Портов наружу нет. Видит
весь каталог данных. Книгу открывает только он.

**web** (`audiobux web`). Отдаёт интерфейс и API. Книг не разбирает и моделей
не видит: из каталога данных у него только `incoming/` (сюда пишет загрузки),
`library/` только для чтения, `run/` (сокет), `web/` (свои базы:
`listening.db` - где слушатель остановился и прослушана ли книга, `auth.db` -
хэш пароля и сессии) и `tls/` только для чтения (сертификат). Контейнер
только для чтения, 512 МБ памяти, не больше 64 процессов. Выход его сети в
интернет закрыт (`enable_ip_masquerade: false`).

**cover** (`coverfinder/`). Маленький HTTP-сервис: по автору и названию ищет
обложку в LitRes и Open Library и отдаёт картинку или пустой 404. Книг и
секретов у него нет. Достучаться до него может только worker по внутренней сети
`cover_in`; в интернет он выходит через отдельную сеть `cover_out`. Контейнер
только для чтения, пользователь 65534, 128 МБ, полпроцессора, 32 процесса.

Все три контейнера работают без capabilities (`cap_drop: [ALL]`) и с
`no-new-privileges`. worker и web запускаются от `AUDIOBUX_UID:AUDIOBUX_GID`.

### Сокет worker

Веб обращается к worker только через `run/worker.sock` (права 0600). Протокол
описан в `audiobux/contract.py`: одна строка JSON на запрос
`{"method": ..., "params": ...}`, одна на ответ. Методов семь, лишних полей в
`params` быть не может:

| Метод | Параметры | Что делает |
|---|---|---|
| `book.submit` | `upload_id`, `title` | забирает загрузку из `incoming/` и ставит книгу в очередь |
| `book.delete` | `id` | удаляет книгу; если она озвучивается, останавливает её |
| `book.retry` | `id` | возвращает упавшую книгу в очередь |
| `library.list` | - | все книги, очередь тоже |
| `book.get` | `id` | одна книга с главами |
| `status.read` | - | модели, карта, очередь, тихие часы, принимаемые форматы |
| `events.subscribe` | - | поток событий: книга изменилась, удалена, ping каждые 15 с |

Ограничения: `id` - 32 шестнадцатеричных символа, запрос не больше 4096 байт,
название не длиннее 200 символов, запрос должен прийти за 3 с, ответ ждётся до
60 с. Ошибки приходят кодом: `bad-request`, `unknown-method`, `too-large`,
`timeout`, `not-found`, `not-a-book`, `conflict`, `unavailable`, `internal`.

### Веб

Все ручки под `/api`, описание - `docs/openapi.json` (`audiobux openapi`).
Страницы документации API (`/docs`, `/redoc`) выключены.

- Загрузка: `POST /api/books?name=<имя файла>`, тело - сам файл. Ответ 201 для
  новой книги, 200 для уже известной, 413 для файла больше
  `AUDIOBUX_UPLOAD_MB`, 415 для неизвестного формата. Файл не принимается
  вовсе, пока в очереди (ждут или озвучиваются) `AUDIOBUX_QUEUE_MAX` книг -
  429 `{"detail":"queue-full"}`, и пока в каталоге данных свободно меньше
  `AUDIOBUX_MIN_FREE_GB` ГБ - 507 `{"detail":"no-space"}`.
- Аудио отдаётся с `Range` (один диапазон), чтобы плеер мог перематывать.
- События для интерфейса: `GET /api/events` (Server-Sent Events).

Проверки на каждом запросе:

- при `AUDIOBUX_LOGIN` не `off` нужен вход (fastapi-users, `audiobux/auth.py`):
  пользователь один, `admin`, вход `POST /api/auth/login` формой
  `username`/`password`, выход `POST /api/auth/logout`. Сессия - кука
  `audiobux` (HttpOnly, Secure, SameSite=Lax) на 30 дней; в `auth.db`
  от сессии только SHA-256 её токена, сам токен есть лишь в куке.
  Без входа API отвечает 401 `{"detail":"unauthorized"}`, страницы
  перенаправляют на `/login`; открыты только `GET /api/auth` (нужен ли вход),
  сам вход и файлы интерфейса. После 5 попыток входа подряд без верной с
  одного адреса вход отвечает этому адресу 429 `{"detail":"too-many-attempts"}`
  15 минут; верный вход счёт сбрасывает, счёт в памяти процесса. Пароль
  задаёт `audiobux password` (читает из stdin, с `--keep` не меняет заданный),
  не короче 12 символов; новый пароль закрывает все сессии;
- `Host` должен быть IP-адресом, `localhost` или именем из `AUDIOBUX_HOSTS`,
  иначе 403 `{"detail":"forbidden"}`;
- у POST, PUT и DELETE должен быть заголовок `Origin` с тем же хостом;
- на всех ответах `Content-Security-Policy: default-src 'self'; base-uri 'none';
  form-action 'self'; frame-ancestors 'none'; object-src 'none'`,
  `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`.

Интерфейс (Svelte, `frontend/`) собирается в образ и отдаётся тем же процессом.

## Очередь

Состояния книги: `queued`, `running`, `paused`, `done`, `failed`. worker берёт
следующую книгу, когда модели скачаны и сейчас не тихие часы. После перезапуска
начатые книги снова встают в очередь первыми и продолжают с того шага, на
котором остановились.

При загрузке worker переносит файл в `work/<id>.upload`, определяет формат по
первым байтам (`%PDF-`, `AT&TFORM` для DjVu, zip для EPUB) и считает sha256.
Файл с тем же sha256 - уже известная книга, вторая не заводится. Исходник
ложится в `library/<id>/source.<расширение>`.

Удаление книги во время озвучки срабатывает на ближайшей проверке (перед
страницей, главой или раундом кусков). `book.retry` принимает только книгу в
состоянии `failed`, иначе `conflict`.

## Конвейер

Шаги в `audiobux/pipeline.py`, по порядку. Каждый пишет свой результат в
`work/<id>/` и ставит отметку `<шаг>.done`; при повторе сделанные шаги
пропускаются. Между шагами worker снимает модели с карты: следующий шаг
загружает свою.

| Шаг | Что делает | Пишет |
|---|---|---|
| `extract` | достаёт текст, оглавление, рисунки и обложку из файла; у скана - страницы картинками | `text.json` или `scan.json`, `cover.jpg`, `page1.jpg` |
| `ocr` | только для сканов: языковая модель с картинками читает страницы, размечает заголовки и рисунки | `text.json`, `figures.json` |
| `figures` | рисунки и таблицы описываются словами (модель смотрит на картинку и подпись) | `described.json`, `figures.json` |
| `fix` | языковая модель правит текст: переносы, мусор распознавания; листинги кода пересказывает одной фразой | `fixed.json` |
| `epub` | собирает EPUB с текстом для чтения; если не вышло, книга озвучивается дальше без него | `book.epub` |
| `normalize` | числа, даты, сокращения и знаки формул словами, капс обычными буквами (аббревиатуры остаются), латиница по словарю книги, ударения (RUAccent) | `normalized.json`, `latin.txt` |
| `chunk` | режет текст на куски по длине, которую голос читает за раз | `chunks.json` |
| `tts` | озвучивает куски раундами по 32 | `tts/NNNNN.wav` |
| `verify` | каждый кусок слушает Whisper и выравнивает по словам; кусок с ошибками, заиканием или разрывом в слове озвучивается заново с другим seed, до 3 попыток; паузы ставятся по тексту | `ready/NNNNN.wav`, `ready/NNNNN.json`, `verify.json` |
| `assemble` | склеивает куски, выравнивает громкость в два прохода, кодирует AAC 64k, ставит главы, теги и обложку | `book.m4b`, `chapters.json` |
| `sync` | время каждого предложения в m4b для подсветки текста | `sync.json`, `figures/*.jpg` |

После `sync` worker переносит `sync.json`, рисунки, `book.epub`, `cover.jpg` и
`book.m4b` в `library/<id>/` и удаляет `work/<id>/`.

Подробности шагов:

- Кусок, который так и не прошёл проверку за 3 попытки, берётся в лучшем из
  вариантов и записывается в `verify.json`; книга не останавливается. Порог -
  доля ошибочных букв (CER) больше 0,15.
- Паузы между кусками зависят от знака: внутри фразы 0,22 с, запятая 0,40,
  конец предложения 0,80, абзац 1,10, заголовок 1,40, новая глава 2,0
  (`audiobux/takes.py`).
- Громкость: `loudnorm` с целью I=-18, TP=-3, LRA=11 (`audiobux/m4b.py`).
- Словарь латиницы `work/<id>/latin.txt` пишет языковая модель один раз; его
  можно поправить руками, и при следующем запуске шага он берётся как есть.
- EPUB-исходник идёт в читалку как есть, из других форматов EPUB собирается.
  Его оглавление - главы m4b одним уровнем, как в плеере; заголовки глубже и
  строки напечатанного содержания в него не попадают.
- Из текстового слоя PDF слово, разорванное пробелом («ЧЕТЫ РЕ»), склеивается,
  если обе части в книге отдельно нигде не встречаются, а целое слово
  встречается. Мягкий перенос в конце блока или страницы склеивает слово со
  следующим блоком.
- Шаги `ocr` и `figures` на карточке появляются, только если у книги есть скан
  и рисунки; в процент они без этого тоже не входят.

### Книги прежнего разбора

Разбор книги (название и автор, главы) меняется от версии к версии, озвучка
занимает часы. У книги в базе записана версия разбора, с которой она готова
(`parse`, `audiobux/refresh.py`, `VERSION`). Когда очередь пуста, модели на
месте и сейчас не тихие часы, worker берёт готовую книгу со старой версией и
разбирает её заново без озвучки:

- из исходника снова достаются оглавление, название и автор (с титула и выходных
  данных, языковой моделью, как в шаге `extract`);
- заголовки глав ищутся в тексте, по которому книга озвучена, как он записан в
  `sync.json`: блок, который читается как заголовок или начинается с него, и после
  которого в ближайших 8 блоках есть первые абзацы главы. Строка озвученного
  оглавления так не подходит, за ней другие заголовки. Текст до первой главы
  (титул, оглавление, если их озвучили) - отдельная глава с названием книги;
- `sync.json` делится на эти главы, время предложений прежнее; EPUB собирается
  заново из того же текста (исходник EPUB остаётся как есть);
- в `book.m4b` заменяются теги и метки глав, звук и обложка копируются без
  перекодирования.

Кусков звука для этого не нужно: их нет после публикации. Нет `book.m4b` - главы
обновляются только в базе и в `sync.json`; нет `sync.json` - только название и
автор. Готовое кладётся в `library/<id>/` только целиком. Если разбор упал, книга
остаётся как была и слушается, ошибка в журнале worker, и до следующей версии
разбора книга заново не берётся.

### Обложка

`audiobux/cover.py`: сначала своя обложка книги, если её нет - поиск через
`cover` по автору и названию (их можно взять из имени файла вида
`Автор - Название`), если не нашлось - первая страница. Картинка из сети
принимается только JPEG, PNG или WEBP, не больше 10 МБ и 40 млн пикселей,
сторона от 200 пикселей, высота к ширине от 0,9 до 2,0; worker перекодирует её
в JPEG (`audiobux/webcover.py`).

### Тихие часы

`audiobux/quiet.py`. Окно `ЧЧ:ММ-ЧЧ:ММ`, может переходить через полночь,
время местное, по часам и поясу машины (`/etc/localtime` хоста смонтирован в
контейнеры). Проверка идёт перед каждой страницей распознавания,
главой правки и раундом кусков. Когда окно началось, языковая модель
останавливается, остальные модели снимаются с карты, книга ждёт. Новая книга в
тихие часы не начинается.

## Модели

Загрузка - `audiobux/fetch.py`. Контейнер fetch (`audiobux fetch`) качает всё,
что нужно по настройкам, в `models/`, пишет ход в свой журнал и каждые 5 с в
`models/.fetched/progress.json` (байты скачаны и всего, упал ли). После сбоя
повторяет через 10, 30, 60 и 300 с. Скачанное отмечается в `models/.fetched/`,
при следующем запуске проверяются только отметка и наличие файлов, без сети.
worker проверяет то же при старте и потом каждые 5 с: пока не всё на месте,
книги принимаются, но не озвучиваются, а скачать недостающее worker не может.
Ход из `progress.json` worker отдаёт в `status.read` (`models.done`,
`models.total`), интерфейс рисует полосу. fetch упал или файл не обновлялся
60 с - `models.failed`, интерфейс пишет «Модели не скачались»; повторный
`./install.sh` запускает fetch снова, и он продолжает с того же места.

Каждая модель закреплена в таблице `PINNED` в `fetch.py`: коммит репозитория на
Hugging Face и sha256 каждого файла. Список файлов закреплённой модели берётся
из таблицы, без запроса к Hugging Face. Файл на месте, но с другим sha256,
удаляется и качается заново; скачанный файл с другим sha256 тоже удаляется, и
загрузка повторяется после паузы. Отметка хранит sha256 файлов, поэтому отметка
без них или с другими не принимается, и файлы проверяются заново. Языковая
модель и Whisper при загрузке просят ту же ревизию. Вокодер F5 библиотека F5
берёт с основной ветки репозитория, поэтому `fetch.py` после загрузки
записывает в кеш, что основная ветка - это закреплённый коммит.

worker работает в офлайне (`HF_HUB_OFFLINE=1` в `compose.yaml` и `fetch.offline()`):
библиотека Hugging Face отказывает в любом запросе, transformers не ищет
safetensors на замену закреплённым весам выравнивателя. Модели дальше читаются
только с диска, недостающий файл - ошибка, а не загрузка. `audiobux book`
моделей не качает, берёт скачанные fetch.

| Модель | Зачем | Где |
|---|---|---|
| Qwen3.6-35B-A3B, `UD-Q4_K_M` GGUF + `mmproj-F16.gguf` | распознавание сканов, описание рисунков, правка текста, числа и латиница | `models/hf` |
| F5-TTS_RUSSIAN (`Misha24-10/F5-TTS_RUSSIAN`) + вокодер `charactr/vocos-mel-24khz` | голос | `models/hf` |
| wav2vec2-large-xlsr-53-russian | выравнивание слов в куске | `models/hf` |
| faster-whisper `large-v3-turbo` | проверка озвучки на слух | `models/whisper` |
| RUAccent `turbo3.1` | ударения | `models/ruaccent` |

Языковая модель работает в
одном `llama-server` (выпуск llama.cpp b12063 для CUDA 12, ставится в `runtime/`) на распознавание, рисунки и текст,
8 запросов параллельно, контекст 8192; сервер живёт только пока шаг им
пользуется.

Голос - образец `voice/m1.wav` с текстом `voice/m1.txt`. F5 читает с темпом 0,9,
32 шага, seed первой попытки 42.

## Данные на диске

```
AUDIOBUX_DATA/
  audiobux.db          библиотека и очередь (SQLite, WAL)
  incoming/              загрузки от web, пока worker их не взял
  library/<id>/          source.<расширение>, book.m4b, book.epub,
                         cover.jpg, sync.json, figures/*.jpg
  work/<id>/             промежуточные файлы конвейера, удаляются после публикации
  work/<id>.upload       загрузка, которую worker сейчас принимает
  models/                модели; hf/, whisper/, ruaccent/, .fetched/
  runtime/<хеш>/         рантайм моделей по pylock.runtime.toml: site/, llama/
  run/worker.sock        сокет worker
  web/listening.db       позиции и отметки «прослушано» (пишет только web)
  web/auth.db            хэш пароля argon2 и SHA-256 токенов сессий, права 600
  tls/cert.pem, key.pem  самоподписанный сертификат web, его выпускает install.sh
```

## sync.json

Текст для чтения с временем в m4b. Время - секунды от начала файла; у блока,
который не звучит (листинг без пересказа, заголовок, которого нет в речи),
`t0` и `t1` - `null`.

```json
{
  "version": 1,
  "duration": 5321.4,
  "chapters": [
    {
      "title": "Глава 1",
      "t0": 0.0,
      "t1": 812.6,
      "blocks": [
        {"type": "h", "text": "Глава 1", "t0": 0.0, "t1": 1.2},
        {"type": "p", "sentences": [{"text": "Первое предложение.", "t0": 1.4, "t1": 3.9}]},
        {"type": "figure", "src": "figures/fig_1.jpg", "alt": "На рисунке ...", "t0": 4.1, "t1": 9.0},
        {"type": "code", "text": "print(1)", "t0": null, "t1": null}
      ]
    }
  ]
}
```

Время предложения берётся из выравнивания слов в куске. Если выравнивание не
уверено в слове или кусок не проверялся, время делится по буквам между
соседними словами.

## Настройки

Все переменные `AUDIOBUX_*` и их значения в коде (`audiobux/config.py`).
`compose.yaml` передаёт контейнерам только `DATA`, `TTS`, `QUIET_HOURS`,
`COVER_URL`, `HOSTS`, `LOGIN`, `UPLOAD_MB`, `QUEUE_MAX` и `MIN_FREE_GB`; `DATA`, `VOICE`, `RUNTIME` и `FRONTEND` задаёт ещё и `Dockerfile`, остальные действуют со значением из кода.

| Переменная | По умолчанию в коде | Что задаёт |
|---|---|---|
| `AUDIOBUX_DATA` | `data` (в образе `/data`) | каталог данных |
| `AUDIOBUX_RUNTIME` | пусто = рантайм уже в окружении (в образе worker `/app/pylock.runtime.toml`) | lock-файл рантайма моделей, который worker ставит в `<data>/runtime/` |
| `AUDIOBUX_SOCKET` | пусто = `<data>/run/worker.sock` | сокет worker |
| `AUDIOBUX_QUIET_HOURS` | пусто = круглые сутки | тихие часы |
| `AUDIOBUX_TOC_DEPTH` | `2` | глубина оглавления для глав |
| `AUDIOBUX_TTS` | `tone` (в compose `f5`) | голос: `f5`, или `tone`/`silence` для проверок без модели |
| `AUDIOBUX_VOICE` | `voice/m1.wav` (в образе `/app/voice/m1.wav`) | образец голоса |
| `AUDIOBUX_VOICE_TEXT` | пусто | текст образца |
| `AUDIOBUX_LLM` | Qwen3.6-35B-A3B `UD-Q4_K_M` | языковая модель |
| `AUDIOBUX_OCR` | та же | модель распознавания |
| `AUDIOBUX_OCR_VISION` | `mmproj-F16.gguf` | часть модели для картинок |
| `AUDIOBUX_FIX_MAX_CHANGE` | `0.1` | насколько правка может изменить абзац; ответ модели сильнее этого отбрасывается |
| `AUDIOBUX_ACCENT` | `turbo3.1` | модель RUAccent |
| `AUDIOBUX_STRESS` | `plus` | ударения знаком `+` |
| `AUDIOBUX_ASR` | `large-v3-turbo` | модель Whisper; пусто - без проверки на слух |
| `AUDIOBUX_VERIFY_CER` | `0.15` | порог ошибок куска |
| `AUDIOBUX_VERIFY_ATTEMPTS` | `3` | попыток на кусок |
| `AUDIOBUX_UPLOAD_MB` | `1024` | предел загрузки, МиБ |
| `AUDIOBUX_QUEUE_MAX` | `20` | сколько книг может быть в очереди, готовые и упавшие не в счёт |
| `AUDIOBUX_MIN_FREE_GB` | `5` | меньше свободного места в каталоге данных, ГБ, - загрузка не принимается |
| `AUDIOBUX_HOSTS` | пусто | имена хостов для web |
| `AUDIOBUX_LOGIN` | `on` | вход в web; `off` - без входа |
| `AUDIOBUX_FRONTEND` | `frontend/dist` (в образе `/app/static`) | собранный интерфейс |
| `AUDIOBUX_COVER_URL` | пусто = обложка в сети не ищется (в compose `http://cover:8080`) | адрес сервиса cover |
